# UEC TimeTable MVP

## 1. アプリの要件定義

電気通信大学の学域生が、毎学期の時間割、教室メモ、単位取得状況、卒業要件、課題メモをローカルブラウザ内で一元管理するMVP。対象は情報理工学域のⅠ類・Ⅱ類・Ⅲ類を中心にし、夜間主課程やクラウド同期へ拡張できる構造にする。

MVPの保存方式は`localStorage`。成績CSV、授業、教室、課題、手入力要件、追加科目候補をJSONバックアップとして移行できる。

公式シラバス・学修要覧の自動スクレイピングはMVPでは行わない。学修要覧由来の同梱JSONと、ユーザーのCSV/JSONインポートを優先する。

## 2. 画面設計

- ダッシュボード: 進級・卒業リスク警告、今日の授業、次の授業、次の教室、移動警告、履修単位、卒業進捗、3年/4年進級目安、締切、空きコマ。
- 時間割: PCは月〜土×1〜7限の表、スマホは曜日カード。衝突警告、授業追加、科目検索、取得済み科目除外。
- 授業詳細/編集: 基本情報、曜日時限、単位、区分、教室、建物名、URL、メモ、課題・試験メモ。
- 単位管理: 総取得単位、必要単位、不足、履修中込み予測、区分別進捗、必修未取得、落単/再履修予定。
- 課題・予定: 課題、レポート、試験日、完了状態、通知設定、Google Calendarリンク、iCal出力。
- 共有: 自分の時間割共有リンク生成、友達の共有リンク取込、共通空きコマ、同じ授業、友達の授業一覧。
- 教室: 教室メモ、マップURL、授業ごとの場所、連続授業の建物移動警告。
- 成績分析: 成績CSVからGPA、学期別取得単位推移、評語分布、落単・再履修候補を可視化。
- 設定: 入学年度、学域・類・プログラム、テーマ、確定成績CSV、バックアップ、科目候補CSV/JSON、必要単位の手入力上書き、初期化。

## 3. データモデル

主要型は`src/types.ts`に定義。

- `Course`: 授業名、教員、曜日、時限、学期、単位、区分、教室、URL、メモ、色、履修状態。
- `Classroom`: 教室名、建物、番号、地区、階、メモ、よく使うフラグ。
- `CreditRequirement`: 入学年度、学域、類、プログラム、総必要単位、区分別必要単位、必修科目名。
- `Assignment`: 授業ID、課題名、締切、種別、URL、メモ、完了。
- `FriendSchedule`: 共有された表示名、エクスポート日時、比較用の授業一覧。
- `NotificationSettings`: 課題通知の有効化、標準通知日数、標準通知時刻、授業前通知分。
- `GradeCsvImport`: 確定成績CSV由来の学生設定候補と成績レコード。

## 4. コンポーネント設計

- `App`: 状態、永続化、カタログ読み込み、画面遷移、単位集計を統括。
- `Shell`: ヘッダー、ナビゲーション、テーマ切替。
- `Dashboard`: 毎日見る運用面。
- `Timetable`: 週間表、スマホ曜日カード、科目検索。
- `CourseModal`: 授業詳細、編集、課題メモ。
- `CreditsView`: 単位監査、進捗バー、未取得/再履修一覧。
- `CalendarView`: 課題・試験登録、通知設定、Google Calendarリンク、iCal出力。
- `ShareView`: 共有リンク生成、共有リンク取込、空きコマ比較。
- `CampusView`: 教室メモ管理、マップリンク、連続授業移動警告。
- `AnalysisView`: GPA、学期別推移、評語分布、落単・再履修候補。
- `SettingsView`: CSV/JSON入出力、ユーザー設定、必要単位上書き。
- `storage/repository.ts`: 保存層。将来Supabase/Firebase実装へ差し替え可能。

## 5. 実装コード

Vite + React + TypeScript + Tailwind CSSで実装。学修要覧・科目カタログは`public/data`配下に配置する。公式地図・3Dマップ・学修要覧PDF本文や原表テキストは公開版へ同梱しない。

## 6. サンプルデータ

個人情報を含む添付CSVはアプリに埋め込まず、設定画面からユーザーがローカルで取り込む。

## 7. 起動方法

```bash
npm install
npm run dev
```

ブラウザで`http://localhost:5173`を開く。

本番ビルド確認:

```bash
npm run build
npm run preview
```

- 複数端末間のクラウド同期。
- 公式キャンパスマップとの深い連携。
