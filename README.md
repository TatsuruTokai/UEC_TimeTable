# UEC TimeTable

電気通信大学の学域生向けに作成している、ブラウザベースの時間割・単位管理アプリです。履修計画、成績CSVからの取得単位集計、進級・卒業要件の確認を1つの画面で扱えることを目的にしています。

公開版: https://tatsurutokai.github.io/UEC_TimeTable/

## 主な機能

- 初期設定で入学年度、年次、類、プログラムを設定
- 学務情報システムから出力した成績CSVを読み込み
- 成績CSVから入学年度、年次、類、プログラムを自動推定
- 週間時間割の表示と授業登録
- 1限から5限までの時間割表示
- 授業ごとの教室・建物名メモ
- 単位取得状況、3年進級要件、4年進級要件、卒業要件の詳細確認
- 入学年度・類・プログラム別の構造化要件データによる進級判定補助
- 不足区分に応じた履修候補の表示
- 科目データ、成績データ、バックアップデータのインポート/エクスポート
- localStorageによるブラウザ内保存
- ダークモード対応

## 対象

- 電気通信大学 情報理工学域
- Ⅰ類（情報系）、Ⅱ類（融合系）、Ⅲ類（理工系）
- 2020年度から2026年度入学の学修要覧由来データ
- 3年次以上はプログラム別の科目・要件データに対応

## CSVの取得方法

初回利用時は、学務情報システムから出力した成績CSVの添付が必要です。

1. 学務情報システムを開いてログインする
2. スマホでは左上の三本線、PCでは左側タブを開く
3. 「教務・授業関連」から「成績」を開く
4. 「単位修得状況照会」を開く
5. 「過去を含めた全成績」を選び、「ファイルに出力」から「ファイル出力開始」を押す
6. 出力されたCSVをアプリの初期設定画面に添付する

## データ構成

公開データは `public/` 以下に配置しています。

- `public/data/all_subjects.json`: 科目候補データ
- `public/data/graduation_requirements.json`: 卒業要件データ
- `public/data/promotion_requirements.json`: 3年・4年進級要件データ
- `public/data/category_aliases.json`: 区分名の表記ゆれ対応
- `public/data/subject_aliases.json`: 科目名の表記ゆれ対応

## 進級・卒業要件の扱い

単位管理画面では、次の3種類をタブで確認できます。

- 3年進級: 2年次終了時審査の総単位、区分別単位、指定科目条件
- 4年進級: 卒業研究着手審査の総単位、共通条件、プログラム別条件
- 卒業: 卒業所要単位の区分別進捗

判定では、取得済み単位、履修中・予定込みの見込み単位、不足単位、未充足区分、未取得必修・指定科目を表示します。機械的に確定しにくい科目数条件や特例は、`confidence`、`manual-review`、注意文としてデータ内に残しています。

## 保存方式と個人情報

このMVPはログイン不要のローカル保存型アプリです。読み込んだ成績CSVの内容、時間割、教室、設定情報は利用者のブラウザ内の `localStorage` に保存されます。

現在の実装では、アプリ側から成績CSVや個人情報を外部サーバーへ送信しません。ただし、同じブラウザを共有している場合や端末を譲渡する場合は、設定画面からデータ初期化を行ってください。

## 注意事項

進級要件・卒業要件は、入学年度、類、プログラム、履修状況によって変わります。このアプリの判定は確認補助であり、最終的な進級・卒業要件は必ず公式の学修要覧・教務課資料で確認してください。

公開版では、公式地図・3Dマップ・学修要覧PDF本文や原表テキストの再配信は行いません。公開データは判定補助に必要な構造化データと出典リンクに限定します。

公式シラバスや学修要覧の自動取得を行う場合は、利用規約、著作権、アクセス負荷に注意してください。
